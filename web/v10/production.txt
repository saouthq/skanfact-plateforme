La page Production (brique 48). Format : voir sans-paquets.mjs.

Le tableau de production lit ce que le serveur compte pour tout le portefeuille (docs/cabinet.md,
C38). Ses mots sont ceux du Cabinet sans paquets (C14) : un mois ÉCRIT a des écritures dans ses
livres ; un mois passé sans aucune écriture est MANQUANT. Et il se relit chaque fois qu'on entre sur
la page : la v10 le lisait une fois, et un mois saisi dans la journée y restait « à saisir ».

== cabinet/app.js | le tableau de production se relit chaque fois qu'on entre sur la page
-- avant
    if (route !== routeLue && (route === 'echeances' || route === 'dossiers')) chargerQuestionsAttente(true);
-- après
    if (route !== routeLue && (route === 'echeances' || route === 'dossiers')) chargerQuestionsAttente(true);
    // (plateforme) Le tableau de production se relit quand on ENTRE sur sa page : lu une fois, un mois
    // saisi dans la journée y restait « à saisir » (même règle que le résumé ci-dessus).
    if (route !== routeLue && route === 'production') prodState.lignes = null;
-- fin

== cabinet/cabguide.js | la bulle de la Production : ce qu'elle lit, sans paquets
-- avant
    'eq.production': { t: 'Le tableau de production', d: 'Par client et par mois : <b>reçu → saisi → révisé → déclaré</b>, qui et depuis quand. Un mois passé sans aucune écriture d\'un client sur SkanFact est « manquant ». « Révisé » affiche « — » tant que le mois n\'a rien dans ses livres : ne pas savoir n\'est pas « non ».' },
