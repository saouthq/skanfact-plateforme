L'état El Fatoora dans la liste des factures (brique 139), et signer plusieurs pièces d'un coup (brique 140) ; web/public/plateforme/pont.js ; docs/facture-electronique.md, L et M.
Format : voir sans-paquets.mjs.

Sous le statut d'une facture ou d'un avoir émis d'une entreprise soumise à la facture électronique, la liste dit où en
est son fichier El Fatoora (à signer, en route, déposé, accepté, refusé…) : le point de contact le demande au serveur,
en un appel pour toute la page.

== app.js | la colonne « Statut » garde une place pour l'état El Fatoora d'une pièce émise ; le point de contact la remplit
-- avant
      { key: 'status', label: 'Statut', val: d => effStatus(d), get: d => statusBadge(d) },
-- après
      { key: 'status', label: 'Statut', val: d => effStatus(d), get: d => `${statusBadge(d)}${bridge.etatsTtn && company().efacture === true && (d.type === 'facture' || d.type === 'avoir') && d.number && !d.ticket ? `<span class="ttn-etat" data-ttn="${h(d.id)}"></span>` : ''}` },
-- fin

── Signer plusieurs pièces d'un coup (brique 140) ──

== app.js | à côté du titre de la liste des factures, une place pour « Signer les N pièces en attente… » (rien ne bouge quand le bouton y paraît)
-- avant
      <div class="page-head"><h1>${isQ ? 'Devis' : 'Factures'}</h1>
-- après
      <div class="page-head"><h1>${isQ ? 'Devis' : 'Factures'}</h1>${!isQ && bridge.dessinerASigner && company().efacture === true ? '<span id="sg-a-signer" style="margin-right:auto"></span>' : ''}
-- fin

== app.js | le point de contact pose le bouton s'il y a des pièces à signer ; signées, la liste se redessine
-- avant
    if ($('#new-avoir')) $('#new-avoir').onclick = () => navigate('#/doc/new/avoir');
-- après
    if ($('#new-avoir')) $('#new-avoir').onclick = () => navigate('#/doc/new/avoir');
    if ($('#sg-a-signer')) void bridge.dessinerASigner($('#sg-a-signer'), modal, () => render(true));
-- fin
