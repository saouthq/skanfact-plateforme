Toutes les données de l'entreprise (lot équipe, « Télécharger toutes mes données », 12/10/2026 ; migration 0080,
docs/export-complet.md). Format : voir sans-paquets.mjs.

L'onglet « Données et sécurité » des Paramètres ne proposait aucun moyen de récupérer ses données : la plateforme cache
les panneaux de la v10 de bureau qui le faisaient (le fichier, les sauvegardes du disque), et rien ne les remplaçait.
Le panneau « Toutes les données de l'entreprise », en tête de l'onglet, pour le propriétaire et un administrateur (03,
« Export complet ») : il télécharge le fichier complet que le serveur fabrique (plateforme/pont.js, `dessinerExport`).
Jamais bloqué par l'abonnement (07) : c'est une lecture.

== app.js | qui télécharge toutes les données : le propriétaire, un administrateur (les droits du dossier)
-- avant
  // (plateforme, lot équipe) L'onglet de l'équipe ne se montre qu'au propriétaire et à un administrateur : la base refuse
-- après
  // (plateforme, export complet) Toutes les données de l'entreprise ne se téléchargent que par le propriétaire et un
  // administrateur : le serveur refuse à tout autre rôle (03, « Export complet »).
  const exportVisible = () => !!bridge.dessinerExport && !!(bridge.droitsDossier && bridge.droitsDossier().responsable);
  // (plateforme, lot équipe) L'onglet de l'équipe ne se montre qu'au propriétaire et à un administrateur : la base refuse
-- fin

== app.js | le point de contact dessine le panneau quand les Paramètres s'ouvrent
