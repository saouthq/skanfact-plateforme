Les sauvegardes, vues de l'entreprise (lot Fonctions 3, 1.90.0 ; migration 0161, docs/sauvegardes-ecran.md). Format : voir
sans-paquets.mjs.

La v10 de bureau montrait ses copies du disque ; la plateforme cachait ce panneau, et rien ne disait au propriétaire que
ses données étaient gardées. Le panneau « Tes sauvegardes », sous « Toutes les données de l'entreprise », pour le
propriétaire et un administrateur : ce que la veille a vu des copies, et « Demander de revenir en arrière… »
(plateforme/pont.js, `dessinerSauvegardes`).

== app.js | le panneau a son entrée (le sommaire de l'onglet, la recherche des réglages, la palette)
-- avant
    'p-export': { onglet: 'donnees',
-- après
    'p-mes-sauvegardes': { onglet: 'donnees', titre: 'Tes sauvegardes', mots: 'sauvegarde sauvegardes copie copies nuit restaurer restauration revenir arriere minute perdu efface annuler secours', visible: () => exportVisible() && !!bridge.dessinerSauvegardes },
    'p-export': { onglet: 'donnees',
-- fin

== app.js | le panneau, sous « Toutes les données de l'entreprise »
-- avant
      ${exportVisible() ? `${panneau('p-export', info('data.export'))}<div id="export-panel"></div></div>` : ''}
-- après
      ${exportVisible() ? `${panneau('p-export', info('data.export'))}<div id="export-panel"></div></div>` : ''}
      ${exportVisible() && bridge.dessinerSauvegardes ? `${panneau('p-mes-sauvegardes', info('data.mes-sauvegardes'))}<div id="mes-sauvegardes-panel"></div></div>` : ''}
-- fin

== app.js | le point de contact dessine le panneau quand les Paramètres s'ouvrent
-- avant
    if (bridge.dessinerExport && $('#export-panel')) bridge.dessinerExport($('#export-panel'));
-- après
    if (bridge.dessinerExport && $('#export-panel')) bridge.dessinerExport($('#export-panel'));
    if (bridge.dessinerSauvegardes && $('#mes-sauvegardes-panel')) void bridge.dessinerSauvegardes($('#mes-sauvegardes-panel'), { modal, toast });
-- fin
