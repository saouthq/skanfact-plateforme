La messagerie entre l'entreprise et son cabinet (lot messagerie ; maquettes « Mon comptable » et « Les messages de tes
clients » validées par Skander le 09/10/2026 ; docs/messagerie.md). Format : voir sans-paquets.mjs.

L'écran du fil et celui de la boîte vivent dans plateforme/messagerie.js (partagé par les deux applications) ; ces
adaptations ne font que les brancher : l'entrée du menu et sa pastille, la page, et la photo d'un message rangée dans
les achats (elle passe par la lecture de la brique 84, devenue une fonction).

      messagerieOuverte = api.messagerie.boite(racine, {

        toast: (texte, erreur) => toast(texte, erreur ? 'error' : undefined),
        revision,
        ouvrirPiece,
        saisirPiece,
        surCompteurs: c => majPastilleMessages(c.aTraiter),
      });
      return;
    }
    const id = decodeURIComponent(ent);
    const d = (S.dossiers || []).find(x => x.id === id);
    messagerieOuverte = api.messagerie.conversation(racine, id, {
      nom: d ? d.name : 'Ce client',
      demander: geste === 'demande',
      toast: (texte, erreur) => toast(texte, erreur ? 'error' : undefined),
      retour: { texte: 'Les messages de tes clients', aller: () => { location.hash = '#/messages'; } },
      revision: () => revision(id),
      ouvrirPiece: (genre, piece, libelle) => ouvrirPiece(id, genre, piece, libelle),
      saisirPiece: m => saisirPiece(id, m),
      surAttente: () => { void rafraichirPastilleMessages(); },
    });
  }
