Ce que la 1.80.0 change au Cabinet (docs/recette.md, « 1.80.0 ») : une échéance nomme les clients « à valider » et
mène à leur saisie. Format : voir sans-paquets.mjs.

« 1 à valider » sur la TVA de septembre ne disait ni qui, ni où aller : la pastille n'était pas un bouton, et il
fallait chercher le dossier dans la liste (recette du 20/10/2026). Les clients « à saisir au cabinet » avaient déjà
leurs noms et « Ouvrir sa saisie » (10.12.0) : ceux « à valider » aussi — un seul, sa saisie sur l'année du mois ;
plusieurs, la Production.

== cabinet/cabcore.js | l'échéance garde les dossiers à valider
-- avant

-- après
    const manquants = [], provisoires = [], aSaisir = [], aSaisirIds = [], provisoiresIds = [];
-- fin

== cabinet/cabcore.js | un dossier à valider, nommé et retrouvable
-- avant
      else if (etats.some(e => e === 'provisoire')) provisoires.push(d.name);
-- après
      else if (etats.some(e => e === 'provisoire')) { provisoires.push(d.name); provisoiresIds.push(d.id); }
-- fin

== cabinet/cabcore.js | l'échéance rend les dossiers à valider
-- avant
      clients, manquants, provisoires, aSaisir, aSaisirIds,
-- après
      clients, manquants, provisoires, aSaisir, aSaisirIds, provisoiresIds,
-- fin

== cabinet/app.js | « Valider ses écritures » ouvre la saisie du dossier, sur l'année du mois
-- avant
    $$('[data-vers-production]', view).forEach(b2 => { b2.onclick = () => { location.hash = '#/production'; }; });
-- après
    $$('[data-vers-production]', view).forEach(b2 => { b2.onclick = () => { location.hash = '#/production'; }; });
    $$('[data-valider-dossier]', view).forEach(b2 => {
      b2.onclick = () => { location.hash = '#/dossier/' + encodeURIComponent(b2.dataset.validerDossier) + '/comptabilite/saisie/' + b2.dataset.annee; };
