Ce que la 1.80.0 change à l'application de l'entreprise (docs/recette.md, « 1.80.0 ») : une pièce négative ne s'émet
pas. Format : voir sans-paquets.mjs.

L'avoir d'une facture de solde reprend la ligne « Acompte déjà facturé » (−24,000) ; la ligne corrigée baissée à 10,000,
l'avoir faisait −16,660 DT, et « Émettre l'avoir AVO-2026-003 ? Montant de l'avoir − 16,660 DT » se proposait — un avoir
qui AUGMENTE la dette du client (recette du 20/10/2026). Le refus vient avant la fenêtre d'émission, à la porte unique
des deux chemins (« Émettre », « PDF »), et montre les lignes ; le serveur refuse aussi (ventes.avoir_negatif).

  function montantNonEmettable(doc) {
    if (doc.type !== 'facture' && doc.type !== 'avoir') return false;
    const t = C.computeTotals(doc, company());
    const av = doc.type === 'avoir';
    // Hors timbre : le dinar du timbre masquait une petite facture négative.
    const horsTimbre = C.round3(t.netHT + t.totalVAT);

      : `Cette facture fait ${C.money(horsTimbre, docCur(doc))} : une facture négative ne s'émet pas. Pour rendre de l'argent à ton client, fais un avoir.`);
    return true;
