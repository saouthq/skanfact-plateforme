Les pages pensées pour un ordinateur le disent au téléphone (brique 109 ; 14 § 2.6 : « Utilisables mais pensés
pour l'ordinateur : la saisie comptable, la révision, la liasse, la paie complète. Sur un petit écran, ils le
disent. »).
Format : voir sans-paquets.mjs.

Les écrans du quotidien (vendre, encaisser, photographier, l'accueil) sont pensés pour le téléphone ; la
comptabilité, la paie, les immobilisations, les statistiques et les marges restent pensées pour un grand écran.
Au téléphone (sous 760 points, la largeur où `telephone.css` prend la main), elles le disent sous leur titre, au
lieu de laisser croire qu'un tableau à l'étroit est le mieux qu'on puisse faire.

  const PAGES_ORDINATEUR = ['compta', 'paie', 'salarie', 'immos', 'immo', 'stats', 'marges'];
  function bandeauOrdinateur(name) {
    if (!PAGES_ORDINATEUR.includes(name) || !window.matchMedia('(max-width: 760px)').matches || $('#bandeau-ordinateur')) return;
    const tete = $('#view .page-head');
