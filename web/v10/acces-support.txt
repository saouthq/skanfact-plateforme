L'accès du support de SkanFact au dossier (Support S2 ; docs/support.md ; serveur/support, migration 0096 ;
plateforme/acces.js). Format : voir sans-paquets.mjs.

Le support ne voit rien du dossier d'une entreprise (Support S1). Pour l'aider sur ses chiffres, un membre de l'équipe
DEMANDE l'accès depuis la console, avec son motif ; le propriétaire ou un administrateur le voit en haut de chaque page,
l'ACCORDE pour quelques heures (en lecture seulement) ou le refuse, et le RETIRE quand il veut. Chaque page lue est
notée : « Le support de SkanFact », dans Paramètres › L'équipe, les montre. La même application, ouverte depuis la console
(« ?support=… »), est la lecture du support : une bande ambrée en haut de chaque page dit à qui est ce dossier, jusqu'à
quand, et que rien ne s'enregistre.

== app.js | chaque page porte en haut la demande d'accès de l'équipe SkanFact (ou l'accès qui court) ; en lecture pour le support, la bande qui le dit
-- avant
    if (bridge.support) bridge.support.poser(view);
-- après
    if (bridge.support) bridge.support.poser(view);
    // (plateforme, Support S2) La demande d'accès de l'équipe SkanFact, ou l'accès qui court : en haut de tout (on y décide).
    if (bridge.accesSupport) bridge.accesSupport.poser(view, { toast: (t, erreur) => toast(t, erreur) });
    // (plateforme, Support S2) La lecture pour le support : la bande qui le dit, au-dessus de tout.
    if (bridge.lecture) bridge.lecture.poser(view);
-- fin
