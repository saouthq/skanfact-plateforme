Les factures périodiques émises seules (brique 129 ; serveur/v10/contrats.ts ; docs/api-situation.md, S7).
Format : voir sans-paquets.mjs.

Un contrat récurrent peut être « émis seul » : à sa date, SkanFact (le serveur) fabrique la facture comme « Générer les
brouillons » la fabrique, puis l'émet, avec son numéro ; l'abonnement mensuel d'une boutique en ligne, d'abord. Seuls
le propriétaire et l'administrateur font ce choix (il engage l'entreprise) ; la case est grisée pour les autres. Un tel
contrat ne propose plus de brouillon à générer ; sa fiche dit qu'il est émis seul, et dit pourquoi une émission a été
refusée (le serveur la retente au tour suivant, une fois le contrat corrigé).

── Le moteur (core.js) ──

== core.js | un contrat émis seul ne propose pas de brouillon : le serveur émet sa facture
-- avant
    return (data.recurring || []).filter(r => r.active !== false && r.nextDate && r.nextDate <= t);
-- après
    // (plateforme, brique 129) Un contrat émis seul ne propose pas de brouillon : le serveur émet sa facture à sa date.
    return (data.recurring || []).filter(r => r.active !== false && !r.emettreSeul && r.nextDate && r.nextDate <= t);
-- fin
