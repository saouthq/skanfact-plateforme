Ce que la recette du 20/10/2026 a trouvé au Cabinet (1.76.0 ; docs/recette.md, « 1.76.0 »). Format : voir
sans-paquets.mjs.

Un cabinet neuf, relié à une entreprise neuve : la page Dossiers ne se relisait pas quand on y revenait, des phrases
disaient qu'il n'y avait rien (aucun mois attendu, aucune écriture) là où le client avait écrit, et des mots restaient
de la paie ou de la v10 (« Adresse de l'employeur », « Abonnements » pour des écritures qui reviennent).

== cabinet/app.js | la page Dossiers se relit quand on y revient
-- avant
  async function refresh() { S = await api.state(); }
-- après
  async function refresh() { S = await api.state(); }
  // (plateforme) 1.76.0 — le portefeuille se relit quand on REVIENT sur Dossiers, comme les index juste en dessous :
  // lu au démarrage, il gardait la proposition d'un client qui n'était pas encore là, et « à valider » sur un mois qu'on
  // venait de valider, jusqu'au rechargement de la page (recette du 20/10/2026). Une lecture à la fois ; la page se
  // redessine si l'on y est encore.
  let lecturePortefeuille = null;
  function relirePortefeuille() {
    if (lecturePortefeuille || !api.state) return;
    lecturePortefeuille = api.state().then(etat => {
      S = etat;
      if ((location.hash.replace(/^#\//, '') || 'dossiers').split('/')[0] === 'dossiers') render();
    }).catch(() => {}).then(() => { lecturePortefeuille = null; });
  }
-- fin

== cabinet/cabguide.js | le guide et l'écriture qui revient, dans l'aide de la saisie
-- avant
Un <b>abonnement</b> est un guide plus une périodicité : le loyer de chaque mois. Les deux <b>proposent</b> — l'abonnement génère en brouillard, jamais une écriture validée que personne n'a regardée. Ils se règlent dans Réglages → Comptabilité, et les abonnements sur la fiche du client.</p>
-- après
Une <b>écriture qui revient</b> est un guide plus une périodicité : le loyer de chaque mois. Les deux <b>proposent</b> — l'écriture qui revient se génère en brouillard, jamais validée sans que personne l'ait regardée. Les guides se règlent dans Réglages → Comptabilité, les écritures qui reviennent sur la fiche du client.</p>
-- fin
