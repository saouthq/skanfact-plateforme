La remise à la caisse (brique 125 ; 03 § 2.1 « Caisse » ; serveur/caisse/remise.ts ; docs/caisse.md, M1 à M4).
Format : voir sans-paquets.mjs.

Le ticket en cours a une remise (%), comptée par le moteur (le même calcul que celui des factures). Au-delà du plafond
de la caisse (Paramètres → Caisse ; 0 % par défaut), un caissier encaisse avec le code d'un responsable présent : la
page le demande AVANT d'encaisser. Le propriétaire et l'administrateur remisent sans code. Sans réseau, une telle remise
ne se vend pas (le code ne se vérifie qu'en ligne).
